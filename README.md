# Profile assets

Discord Webhook 발신 프로필에 사용하는 공개 이미지 저장소입니다.
미터기 소스, 개인 설정, 웹훅 URL 또는 전투 데이터는 포함하지 않습니다.

## Avatar

![프로필 캐릭터](avatar.png)

사용자가 제공한 이미지의 맨 왼쪽 빨간 캐릭터를 AI 이미지 편집으로 분리한 투명 PNG입니다. 원본 전체 이미지는 포함하지 않습니다.

미터기의 `프로필 이미지 URL`에 아래 주소를 입력합니다.

```text
https://raw.githubusercontent.com/neinsys/profile-assets/main/avatar.png
```

이 저장소와 이미지 URL은 공개되어 있으며, 누구나 이미지를 볼 수 있습니다.
